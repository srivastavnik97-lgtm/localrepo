# Foundation Project: Weather App

## 1️⃣ Problem Statement
* **What problem will your app solve?**  
  Unpredictable weather disrupts daily commuting, travel planning, and outdoor activities. Most default weather utilities are cluttered with intrusive ads or fail to clearly present immediate hourly shifts and air quality risks. This app provides fast, hyper-local, and distraction-free weather updates.
* **Why does it matter?**  
  Accurate, easily scannable weather data empowers users to make fast decisions regarding clothing, commuting schedules, and outdoor health precautions (such as high UV indices and poor AQI).

## 2️⃣ Key Features (Top 5)
- Real-time condition tracking (Temperature, Feels Like, Humidity, Wind speed)
- 24-hour hourly outlook & 7-day extended forecasts
- City search with input debouncing and recent search history
- GPS-based device location detection
- Unit conversion toggle (°C / °F) with persistent state

## 3️⃣ Tech Stack
Kotlin, Jetpack Compose, Retrofit, Coroutines & Flow, DataStore, MVVM
